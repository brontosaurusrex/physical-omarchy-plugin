# Frame timing and particle transport — 2026-10-13

Tested on the local Intel HD Graphics 520 machine with Qt's OpenGL backend.

The display supplies elapsed frame time to the Go engine. Skipped requests
accumulate their time; pause/menu/hidden transitions discard unsent animation
time. This removes pipe-processing jitter from the simulation clock. The
240 Hz fixed physics steps, interpolation and collision rules remain unchanged.

Particle shapes are now sent only when first used or changed. Movement travels
in typed batches with full-precision coordinates, rotations and existing colors.
Both sides discard unused outlines, and returning fragments resend them.

## Equivalence and checks

- Old/new engines: exact matching selected physics state and brick caches over
  900 seeded frames on levels 23, 26 and 27, exercising 123,062 particle draws.
  Reconstructed drawing commands agree within a 1e-9 numeric tolerance.
- Native software and actual GPU comparisons: identical particle image pixels,
  including front/back layering, circles, polygons, colors and rotations.
- Transport regression: contour reuse, mutation, disappearance/reappearance,
  full-precision motion and drawing-order boundaries.
- Full `PHYSICAL_TEST_WAYLAND=1 ./check`: passed, including audio, mouse capture,
  keyboard, replay, completion animation, delayed-engine frame timing,
  standalone and compiler-free packaging/install tests.

## Measurements

The deterministic engine benchmark includes physics, drawing-packet preparation
and JSON encoding. These are CPU timings, not displayed FPS. Each result below
averages two 900-frame runs with `GODEBUG=randseednop=0`.

| Level | Previous ms/frame | New ms/frame | CPU time reduction |
| --- | ---: | ---: | ---: |
| 23 | 1.766 | 1.243 | 30% |
| 26 | 2.135 | 1.405 | 34% |
| 27 | 1.501 | 0.824 | 45% |

In the seeded engine comparison, full frame packets averaged 63,476 → 29,612
bytes, a 53% reduction. A separate 150-particle transport regression measured
20,838 → 14,132 bytes for its simpler contour workload.

Two sequential 35-second level-26 stress runs averaged 40.8 → 46.3 active
painted FPS. Median sampled packet parsing fell from 1.71 → 0.65 ms and drawing
compilation from 4.01 → 2.47 ms. These real-time runs have different trajectories
and frame timing; they demonstrate an observed improvement, not a guaranteed
FPS gain. Heavy effects and missed display deadlines can still cause stutter.

A final 120-second stress run rotating levels 26, 23 and 27 passed the external
freeze watchdog with no crash or stall and up to 150 debris fragments. Its
aggregate painted rate was 45.0 FPS, including level transitions and idle
states; heavy scenes still dropped frames. This is a separate real-time run,
not a matched benchmark against the previous version.

## Window frame clock

Animated requests now come from the game window's `afterAnimating` preparation
signal instead of the shared QML `FrameAnimation` clock. The callback runs on
the GUI thread before render synchronization, allowing the separate engine to
prepare its next scene. Request limits, elapsed-time accumulation and fixed
240 Hz physics remain unchanged. Resume and window changes reset the clock,
excluding idle time.

The local display runs at 60.02 Hz. Tests included a second visible Quickshell
window to exercise the multi-window setup, with audio at the default 25%.

| Test | Active painted FPS | Worst UI update gap | Gaps over 25 ms |
| --- | ---: | ---: | ---: |
| Previous clock, level 16 with second window | 59.98 | 32 ms | 5 |
| New clock, level 16 with second window | 60.04 | 21 ms | 0 |
| Final 60-second level 16 run with audio | 60.05 | 21 ms | 0 |
| Final 120-second stress, levels 16/26/23/27 with audio | 56.14 | 44 ms | 381 |

These intervals measure delivery of queued painted-frame notifications to QML,
not physical monitor scanout. Active samples exclude startup, idle screens and
level transitions. Sequential real-time runs can follow different trajectories;
the timing improvement is observed here, not a guarantee for every workload.
Heavy effects still miss some display deadlines.

The full Wayland `./check` passed. The delayed-engine motion regression also
passed with its additional visible window, preserving position accuracy through
long frames, pause/resume and hiding. Software-backend smoke testing passed.
Both final gameplay runs passed the external freeze watchdog without a crash
or stall.
